## Context

I like Dutch language, and in turn, i want a Dutch learning platform that is calibrated for my use case (An Indonesian speaker) but also self paced, not feels like repeating itself, and also has TTS so i can practice the word's pronounciation. So i searched for Dutch curicullum to achieve B1 proficiency and make the web based on that. For each chapter, the quiz will be generated on request using LLM API so that it will not felt repetitive.
