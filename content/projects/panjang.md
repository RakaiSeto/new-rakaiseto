## Context

Ever used a link shortener? Now try the opposite.

Silly? At first I thought so too. Then I noticed there are two kinds of link shorteners: the ones that shorten a link to a readable, customizable name, and the ones that just output a short string of gibberish. This is the second kind — except the link gets *longer*.

![Panjang](/images/projects/panjang/panjang.png)

## The point

It's a joke with a thesis: shortening a link to gibberish adds no information — it just hides the target. Panjang makes that absurdity visible by doing the same thing in reverse. Type a URL, get back something roughly 35 characters longer.

It's built with Vue and Node.js, it's deployed at a domain long enough to make you squint, and the [source is on GitHub](https://github.com/RakaiSeto/panjaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaang).

Try it — if nothing else, it makes a great end to a portfolio.
